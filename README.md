# Sito StoricOmnibus

Sito statico (Jekyll) pubblicato con **GitHub Pages** su https://storicomnibus.it.
I contenuti si modificano dal pannello **Pages CMS**: https://app.pagescms.org

## Dove sta cosa
| Cosa | Dove |
|---|---|
| Contatti, video YouTube, siti amici | `_data/sito.yml` |
| Voci del menu | `_data/menu.yml` |
| Pagine (Chi siamo, Storia, …) | file `.md` nella cartella principale |
| Notizie | `_posts/` (nome file `AAAA-MM-GG-titolo.md`) |
| Gallerie | `_gallerie/` (elenco foto nel campo `foto`) |
| Foto e PDF | `assets/foto/`, `assets/documenti/` |
| Grafica | `assets/css/stile.css`, `_layouts/`, `_includes/` |
| Pannello di modifica | `.pages.yml` |
| Dominio | `CNAME` |

Caricate foto di dimensioni ragionevoli (lato lungo 1600–2000 px): GitHub accetta file fino a 100 MB, ma foto enormi rallentano il sito.
